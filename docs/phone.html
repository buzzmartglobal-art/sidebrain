手机上装 Sidebrain

App 还没上架，所以现在是「借插座」的装法。只有两种活法：当 App 用（30 秒）和 每个网页都有它（装两次，约 5 分钟）。下面每一步都写到你屏幕上会看到什么。

A当 App 用，30 秒

  1. 用 Safari 打开（⚠️ 别在微信里点，微信里加不了主屏幕）： 打开 Sidebrain 手机版 → https://buzzmartglobal-art.github.io/sidebrain/m/
  2. 点底部中间的 分享（方框里一个向上的箭头）
  3. 在列表里往下划，点 添加到主屏幕 → 右上角 添加
    你会看到：桌面上多一个蓝紫图标
  4. 点那个图标 → 输你的邮箱 → 进去就能问
    你会看到：暗色对话界面，底下有输入框、📎、🎤

这就是主力用法。缺点只有一个：它只在自己的窗口里，别的网页上没有。要那个，走 B。

B每个网页都有小精灵（装两次）

苹果不允许网页往别的网页里塞东西，必须借一个免费开源扩展当「插座」。所以要装两样：插座（一次）+ 小精灵（一次）。

第 1 步 · 装插座（Userscripts）

  1. App Store 搜 Userscripts → 获取
    图标是个深色的 </>，作者 quoid
  2. 装完点开它一次，看到设置界面就退出（什么都不用改）
  3. 设置 → 划到 应用 → Safari → 扩展 → 点 Userscripts → 打开开关
    然后在同一页往下找「网站」→ 选 允许（不要选「询问」，选询问就每开一个网站都要点一次）

找不到那一页：在「设置」最上面的搜索框直接打 userscripts，一按就跳过去。

第 2 步 · 把小精灵放进去

走法 ①（最稳，一次就过）下载成文件再拖进去

  1. 回桌面点 Sidebrain 图标 → 右上 ⋯ → 点 ⬇ 下载脚本文件
    Safari 会弹「要下载“Sidebrain.user.js”吗？」→ 点 下载
  2. 开 文件 App → 浏览 → 下载 → 找到 Sidebrain.user.js → 长按它 → 移动
  3. 选 我的 iPhone → Userscripts → 右上 存储
    这里必须选「我的 iPhone」里的 Userscripts 文件夹，别选 iCloud
  4. 打开 Userscripts App → 列表里出现 Sidebrain → 右边开关是开的
    看到 Sidebrain 那一行，就装好了

iPhone 版 Userscripts 没有编辑器和「+」，所以「复制脚本 → 粘贴」那条在手机上走不通（那是 Mac 的用法）。手机上只有上面 ① 和下面 ② 两条。

走法 ②（弹面板就用，不弹就跳过）

  1. ⋯ → ✦ 一键常驻 → 按钮 装到我的 Safari
  2. 弹出「安装脚本」面板后往上滑到底 —— Install 在最底下，紫色那颗
    滑到底都没有按钮：别耗，回上面走 ①（下载文件那条）

第 3 步 · 验证

  1. 用 Safari 随便开一个网页 → 右下角出现 蓝紫药丸（暗色底、写着 Sidebrain）
    出来了 → 成了。点它就能问这一页；选中文字会冒「✦ 存进笔记」
  2. 没出来 → 回 Sidebrain 图标 → ⋯ → 🔎 自检
    它会逐项打勾：服务器通不通、连接码对不对、小精灵跑没跑起来、是不是扩展没开。红在哪一项，就修那一项。

C装完怎么用

  • 问当前网页：点右下角药丸 → 打「这页在讲什么」→ 它带着这一页的内容答
  • 存一段话：在网页上选中文字 → 点「✦ 存进笔记」
  • 存截图/文件：在 Sidebrain 自己的窗口里 📎 加图、加文件，也会进同一个库
  • 翻资料：⋯ → 🗒 笔记；每天早上还会自动生成一份「今日备忘录」

D卡住了，九成是这三件

  1. 在微信里点链接。必须 Safari。微信里的网页既加不了主屏幕，扩展也不生效。
  2. 扩展权限选了「询问」。改回「允许」，否则每开一个新网站都得手动点一次。
  3. 以前装过旧脚本。Userscripts 里如果已经有一条 Sidebrain，先左划删掉，再走第 2 步；两条同名的会打架。

装到一半想放弃也没关系：A 那条（当 App 用）本来就已经能干活了。B 只是让它在别人的网页上也冒出来，不是必需品。
