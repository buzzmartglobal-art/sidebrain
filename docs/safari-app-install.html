Sidebrain for Safari · 安装说明书

自己的扩展上架 App Store 之后，用户看到的就这一份。目标：从零到用上，不超过 6 步，全程不用看源码、不用进第三方面板。

这是上架后给用户的正式说明书（草稿）。App Store 链接、截图位置等扩展通过审核后填。现在写它，是为了把扩展本身的安装体验倒推着定下来 —— 说明书要是超过 6 步，说明产品设计有问题，不是说明书的问题。

0装之前，先看一眼这两件事

  • 要 iPhone 上 iOS 26 以上，或者 Mac 上 macOS 26 以上（Safari 扩展的系统要求）。
  • 准备一个邮箱 + 一个付款方式（前 7 天免费，第 8 天开始 $8/月；不想用了在任何时候取消，不再扣费）。

不用准备 API key，不用挑模型 —— 我们来挑。

1iPhone 上装（6 步）

  1. App Store 搜「Sidebrain」，点 获取。等图标出现在桌面。
    也可以直接点我们给的链接：会自动跳到 App Store 的 Sidebrain 页。
  2. 点开 Sidebrain 这个 App（就一次）。它会显示一个绿勾和一句话：「扩展已经装好了」——这一步只是让系统把扩展注册进去。
  3. 回到桌面，打开 设置 → 往下划到 应用 → Safari → 扩展 → 点 Sidebrain → 打开开关，权限选 允许。
  4. 打开 Safari，随便进一个网页。点地址栏左边的 aA（或分享按钮左边的扩展图标）→ 点 Sidebrain。侧边栏会从右边滑出来。
  5. 输你的邮箱 → 开始用。第一次进来不选模型、不填 key，直接问就行。
  6. （推荐，一次就好）回到 Safari 点 aA → 管理扩展 → 把 Sidebrain 的开关打开到「始终允许」，以后不用每次点。

2Mac 上装（5 步）

  1. Mac App Store 搜 Sidebrain → 获取。
  2. 打开一次 Sidebrain App，让它把扩展注册进系统。
  3. Safari → 菜单栏 Safari → 设置 → 扩展 → 左边点 Sidebrain → 勾上，右边权限选 允许。
  4. 工具栏上出现 Sidebrain 图标 → 点它，侧栏从右边滑出（也可以按 ⌘⇧K）。
  5. 输邮箱 → 用起来。Mac 和 iPhone 用同一个邮箱 = 同一个账号，笔记是同一份。

3装完了怎么用（三件事就够）

想干的事怎么做
问这一页在讲什么点侧栏，直接打「这页在说什么」，它会带着当前网页内容回答
把一段话存进笔记在网页上选中文字 → 浮出「✦ 存进笔记」→ 点一下。照片、文件直接拖/粘进对话框也会存
翻以前的资料侧栏里的 🗒 笔记，每天还会自动给你生成一份「今日备忘录」

回答底下那一行（例如「Gemini · 1.2s」）会告诉你这次是谁答的、花了多久 —— 觉得答得不好，点 👎，下次同样的活它会换一条路。

4三个最常被问的问题

「侧边栏没出来 / 找不到 Sidebrain 图标」

  1. 确认第 3 步的扩展开关是打开的（iOS：设置 → 应用 → Safari → 扩展；Mac：Safari 设置 → 扩展）。
  2. iOS 上点 aA 才会出现扩展列表；Mac 上看工具栏有没有图标，没有就在「显示 → 自定工具栏」里拖出来。
  3. 还不行：重启一次 Safari（iOS 双击 Home 条上划关掉 Safari 再打开）。扩展刚装完，Safari 偶尔要吃一次重启。

「要不要自己填 API key？」

不用。默认走我们的服务器，你只管问。想用自己的 key 也行，设置里有开关（不填就是默认）。

「我的浏览记录/笔记会被看到吗？」

笔记是你自己的 Markdown 文件，能一键导出成 zip。发给模型的只有你问的那一句 + 你当前页面的内容，用来回答问题，不留存、不训练。

5不想用了 / 换设备

  • 只关掉侧栏：Safari 里把扩展开关关掉，网页立刻回到原样。
  • 彻底卸载：删掉 Sidebrain App（iOS 长按图标删；Mac 从「应用程序」拖到废纸篓），扩展跟着走。
  • 换手机：新手机装一次，用同一个邮箱登录，笔记全在。
  • 退订：设置里点取消，到期不再扣费；试用期内取消不收钱。
