Installing is the whole thing

Sidebrain isn't an app you buy and wait for. Pick your device, follow the taps. On a phone it takes two taps and no install at all.

📱 iPhone & iPad nothing to install

No App Store, no extension, no developer settings. It's a web app that behaves like an app.

https://buzzmartglobal-art.github.io/sidebrain/m/
  1. Open that address in Safari (not Chrome — Chrome can't add to the Home Screen properly).
  2. Tap the Share button at the bottom → Add to Home Screen.
  3. Open the new Sidebrain icon and type your email. That's it.

Same email on your Mac = same account, same notes, same trial clock. Nothing to sync by hand.

🔗 Share a page to Sidebrain optional

Once that's working, one file makes the share sheet do the clipping: pick any article in Safari → Share → Sidebrain → it's read, summarised and filed into 剪藏.

  1. Download Sidebrain-Clip.shortcut in Safari.
  2. Tap it → Add Shortcut. (If iOS says it's not allowed: Settings → Shortcuts → turn on Allow Untrusted Shortcuts.)
  3. It asks for your share address once — open Sidebrain → ⋯ → 分享地址 → copy, then paste it in. Done forever.

No shortcut either? You can paste a link straight into the app: 🗒 → 📥 收一篇 → paste → done.

🤖 Android nothing to install

Same web app. Works in Chrome, Edge, Firefox or Samsung Internet.

https://buzzmartglobal-art.github.io/sidebrain/m/
  1. Open the address in Chrome.
  2. Menu ⋮ → Add to Home screen → Add.
  3. Type your email on first open.

Android also gets a real share target later; for now the in-app clip (🗒 → 📥) covers it.

🧩 Mac — way two: the side panel 2 steps

The thing that sits beside every page while you browse. Needs one free extension, then one file.

  1. Mac App Store → install Userscripts (free) → open Safari → Settings → Extensions → allow it.
  2. Copy sidebrain.user.js into the folder Userscripts shows you (there's an Open Scripts Folder button).
  3. Press ⇧⌘K on any page.

Safari only, because that's the browser on this machine. Chrome and Edge can't run this file as-is.

One account, three surfaces: phone web app, desktop web app, Safari side panel. Notes are plain Markdown files — open them in Obsidian if you have it, or export the whole notebook as a zip from ⋯ → 导出笔记库 if you don't.
